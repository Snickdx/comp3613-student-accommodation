# Student Accommodation — public acceptance criteria

Derived from elicitable stakeholder needs (Phase 1). Instructor private defects are **not** listed here.

## Access & scope

1. Closed campus platform: only eligible students browse listing details (registered student ID or provisional incoming pathway).
2. Geography: St. Augustine / Mount Hope listings for St. Augustine students.
3. Referral only — optional in-app messages OK; **no** payments, contracts, or booking checkout.
4. Passwords hashed; login never returns password material.

## Listing lifecycle

5. Landlord submit → **pending** → campus admin **verify** (or reject) → landlord may set **active** / **inactive**.
6. Pending and rejected listings are **not** visible to student seekers.
7. Activate is only allowed after verification (not from pending/rejected).
8. Status and visibility must stay consistent (one clear current state).

## Student browse

9. Students filter by location, price, and amenities; see landlord contact info on visible listings.
10. Optional message threads only against listings students are allowed to see.
